# Welcome collage photographs

One line per file. A file without a line here, or a line without a file, fails
`src/__tests__/welcome-photos.test.ts`.

Welcome is **brand / lifestyle imagery**, not evidence about a venue, so either a licensed photograph or a
generated photograph is allowed here. The `Origin` column must say which (`photograph` or `generated`), so the
record is honest about it. Either way the image must be candid and natural (not posed stock), must contain no
text, logo, watermark or brand mark, and must not depict a specific venue as if it were a FamilyPilot
recommendation.

This is a different contract from Home and Explore, which show real venues and never use generated imagery as a
venue's photograph (see `docs/PHOTOGRAPHY_ASSETS.md`).
